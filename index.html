📟 OBD Error Codes

Diagnostic Trouble Codes की जानकारी

P0487
EGR Throttle Control Circuit
Code: P0487

समस्या: EGR throttle control circuit में समस्या हो सकती है।

Possible Causes:
• Wiring खराब
• Connector loose
• Throttle/EGR valve समस्या
• Sensor या actuator fault

Symptoms:
• Engine warning light
• Power कम होना
• खराब acceleration

Repair:
Wiring और connector check करें। EGR/throttle system की जांच करें।
P0036
HO2S Heater Control Circuit
Code: P0036

Possible Causes:
• Oxygen sensor heater fault
• Wiring problem
• Connector problem
• Fuse या power supply issue

Repair:
Sensor wiring, fuse और connector को check करें।
B2AAA
Manufacturer Specific / Diagnostic Code
Code: B2AAA

इस code का exact meaning vehicle manufacturer और ECU पर depend कर सकता है।

सबसे पहले check करें:
• Vehicle make
• Model
• Engine
• ECU/module
• Scan tool की complete description
